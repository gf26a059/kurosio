# 墨潮 — INK TIDE NOIR

白黒の ASCII で描く、ビルド構築型ローグライク。
お供を雇って表と裏に並べ、絆と装備と基礎パッシブを組み合わせて、15 の波を生き延びます。
最後に待つのは、海の底に鎮座する「海底ケーブル」。

HTML ファイル 1 枚だけで動きます（ビルド不要・外部ライブラリなし）。

## 遊び方

- `index.html` をブラウザで開く
- または GitHub Pages で公開した URL を開く

### 操作

| キー | 内容 |
|---|---|
| W A S D / 矢印 | 移動 |
| J / スペース / クリック長押し | 斬撃（近くの敵を自動で狙う） |
| P / Esc | 一時停止 |
| F | 全画面 |
| M | 音のオン・オフ |
| H | 手当て（「墨の包帯」所持時は戦闘中も） |

ショップでは 1〜4 で雇う、R で引き直し、X で経験値、B で武装箱、T で表⇄裏、V で売却、Enter で出撃。

## 主な仕組み

- **15 の波**：通常の波は 30 秒、5・10・15 波はボス戦（60 秒以内に倒さないと敗北）
- **お供**：表（最大 4 体）で戦い、裏（9 体）は★3 の加護だけが働く。同じお供 3 体で★昇格
- **絆**：陣営（海底火山の箱・墨・広い海洋）と組（近接・射撃・ゲージ・月の加護）の 2 軸。★の数だけ数える
- **装備**：基本装備 6 種、2 つ合わせて上級装備 21 種、絆を足す紋章
- **基礎パッシブ**：8 つのビルド軸に 28 種。レベルアップで選ぶ
- **特殊装備**：真珠・墨の包帯・宝島の鉄砲・一本釣り糸・白い鍵

## 音

効果音と BGM はすべて Web Audio API でその場で合成しています。
BGM は「灯の消えた町」の海アレンジで、ラスボス戦に近づくほど楽器と音量が増えていきます。
